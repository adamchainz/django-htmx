Example project
===============

The django-mcpz repository contains an example project, “Django’s Diner”, in the |example directory|__.
It serves an authenticated MCP endpoint with tools powered by the Django ORM, over a menu of burgers and hot dogs, and its README walks through querying it with curl, Claude Code, and the official MCP Python SDK.

.. |example directory| replace:: ``example/`` directory
__ https://github.com/adamchainz/django-mcpz/tree/main/example
